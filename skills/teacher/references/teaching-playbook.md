# Deep Teaching Playbook

Use this only for a deep lesson, a substantial code walkthrough, or a learning plan.

## Depth

- Beginner: define terms, explain concepts with a small example, and avoid unnecessary implementation detail.
- Intermediate: explain decisions, structure, patterns, and conventions.
- Advanced: focus on trade-offs, architecture, scalability, performance, and maintainability.

## Code And Debugging

- Start with responsibility and data flow, then important functions and decisions.
- For a bug, explain the root cause, nearby failure modes, how to reproduce it, and a debugging method the developer can reuse.
- Prefer an example from the current project; do not invent metrics or project behavior.

## Learning Plan

End substantial lessons with one or two next topics that build directly on the current task. Avoid generic praise or a long curriculum unless requested.
