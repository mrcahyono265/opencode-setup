# Deep Architecture Checklist

Use this only for a substantial architecture decision.

- Database: relationships, keys, indexes, normalization, ownership, query bottlenecks, and migration strategy.
- API: resource names, response consistency, validation, authorization, error behavior, and versioning only when needed.
- Scale: traffic, growth, storage, jobs, cache, query cost, N+1 patterns, network, and memory. Optimize only for demonstrated needs.
- Security: authentication, authorization, input validation, secrets, sensitive-data exposure, and attack surface.
- Maintainability: readability, modularity, coupling, cohesion, testability, and operational complexity.

Read the matching project-planning reference for architecture, API, database, security, or deployment details when it is selected by the project plan.
